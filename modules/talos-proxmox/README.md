# talos-proxmox

> [!WARNING]
> Proof of concept. Built and tested against this homelab's own Proxmox/Talos setup, not hardened or supported for general reuse.

Provisions Proxmox VMs *and* bootstraps a Talos Linux Kubernetes cluster on them in one module (machine secrets/config, image factory schematic, cluster health/kubeconfig).

See [`docs/module.md`](docs/module.md) for the full auto-generated reference (inputs/outputs/resources), and the [Changelog](CHANGELOG.md) for all notable changes.
